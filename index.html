Тема 1.1 — Исторические этапы развития технологий физического уровня передачи данных

📖 Что такое физический уровень?

▶
Физический уровень — первый уровень модели OSI. Он отвечает за передачу сырых битов по физической среде: кабелям, радиоволнам, оптоволокну.

Задачи физического уровня:

  • Кодирование — преобразование бит в физические сигналы
  • Синхронизация — согласование скорости передачи между отправителем и получателем
  • Управление физической топологией — конфигурация среды передачи
  • Определение параметров среды — напряжение, частота, длительность импульса

🕰️ Хронология развития

▶
1837
Телеграф Морзе — первая система электрической передачи данных.
1876
Телефон (Белл) — передача аналогового голосового сигнала по медному проводнику.
1895
Радиосвязь (Попов / Маркони) — беспроводная передача сигнала через электромагнитные волны.
1940-е
Цифровые телефонные линии (T1) — первые каналы для цифровой передачи данных.
1973
Ethernet (Боб Меткалф, Xerox PARC) — стандарт локальных сетей.
1983
IEEE 802.3 — стандартизация Ethernet. 10BASE5.
1990-е
Витая пара + Fast Ethernet — 100BASE-TX.
1998–2002
Gigabit Ethernet + оптоволокно — 1000BASE-T и 1000BASE-SX.
2006–н.в.
10G / 40G / 100G Ethernet + Wi-Fi 6E / 7 — высокоскоростные магистрали.

Тема 1.2 — Типы линий связи

🔌 Классификация линий связи

▶
Линия связи — физическая среда, по которой передаётся сигнал. Делятся на проводные и беспроводные.

Основная классификация:

  • Проводные (кабельные) — витая пара, коаксиальный кабель, оптоволоконный кабель
  • Беспроводные (радиоканалы) — Wi-Fi, Bluetooth, сотовые сети, спутниковая связь
  • Инфракрасные (ИК) — прямая видимость, короткое расстояние

По направлению передачи:

  • Симплексный — только в одну сторону (ТВ-вещание)
  • Полудуплексный — поочерёдно в обе стороны (рация)
  • Полнодуплексный — одновременно в обе стороны (телефон, Ethernet)

📐 Теорема Найквиста и формула Шеннона

▶
Найквист: C = 2 × B × log₂(M)
Шеннон: C = B × log₂(1 + SNR)

Пример: канал 100 МГц, SNR = 1000: C ≈ 1 Гбит/с.

Тема 1.4 — Типы кабелей. Классификация кабельных линий

🔧 Структурированная кабельная система (СКС)

▶
СКС — стандартизированная инфраструктура кабелей. Стандарты: ISO/IEC 11801, TIA-568, ГОСТ Р 53246.

Подсистемы СКС:

  1. Горизонтальная — от розетки до этажного кросса. Макс. 90 м + 10 м шнуры = 100 м.
  2. Вертикальная (магистраль здания) — между этажными кроссами и ГКС.
  3. Кампусная магистраль — между зданиями.
  4. Рабочее место — розетка + патч-корд + NIC.
  5. Телекоммуникационный шкаф — патч-панели, коммутаторы.
